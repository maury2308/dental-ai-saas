# AI WhatsApp Agent for Dental Clinics (SaaS)

A multi-tenant platform allowing business owners to deploy an AI agent for customer service and appointment scheduling via WhatsApp.

## Architecture
- **Frontend**: Next.js (Admin Dashboard)
- **Backend**: Supabase (Auth, DB, Edge Functions)
- **AI**: Claude 3.5 Sonnet
- **WhatsApp**: Meta WhatsApp Business API

## Local Setup
1. Clone the repo
2. Setup environment variables from `.env.example`
3. Run `npm install`
4. Run `npm run dev`
